# Kiddytopia Theme Park Gate System

**Role:** Software Developer  
**Company:** Ticket2U Sdn. Bhd.  
**Duration:** September 2024 – Present  
**Tech Stack:** VB.NET, ASP.NET, SQL Server, Web API

## Overview

This project involved the development and integration of a gate control system for Kiddytopia Theme Park. The system validates visitor tickets and controls gate access in real time, ensuring a secure and seamless check-in process.

## Objectives

- Ensure only valid ticket holders can enter the theme park
- Automate gate control using scanned ticket data
- Improve entry efficiency and reduce manual verification errors

## Key Contributions

- **Designed the gate system UI** using ASP.NET and VB.NET
- **Integrated Web API** to check ticket validity against the database
- **Managed SQL Server database** for ticket storage and status tracking
- **Handled real-time validation logic** for seamless gate operation
- **Conducted thorough testing** to ensure reliability and smooth deployment

## Features

- Web-based interface for staff
- Real-time gate control based on ticket status
- Automated logging for entry tracking
- Integration with existing ticketing system

## Outcome

- Successfully deployed at Kiddytopia
- Reduced entry wait times and improved customer experience
- Minimized gate staff workload through automation
